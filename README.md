Number Guessing Game!


Disclaimer
This project is not intended for individual use. This was made as a practice project for learning how HTML, CSS, and JS interact. However, it is posted online for those to look at it and mess around with it, it just won't do much of anything.

Purpose
This project is a practice project made to experiment with HTML, CSS, and JS. This project will randomly generate a number from 1 to 50, and will expect you to guess said number by writing a number in the text field and clicking the submit button. When the project has ended, you can no longer click the submit button. In the event of guessing a number above 50, no guesses will be deducted and it will notify you to keep your guessed below 50 and above 0. You will have 20 guesses.

Usage
Using this project is easy. Just download the repository and launch index.html in your web browser. Like most projects, it will run from index.html
